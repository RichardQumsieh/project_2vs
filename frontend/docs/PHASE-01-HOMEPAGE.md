# Phase 01 — Homepage

## Goal
Create the first product touchpoint with a premium, privacy-focused visual identity.

## UX direction
- Dark, calm, premium interface
- Minimal navigation
- Large typography
- Floating message bubbles
- Scroll-triggered section reveals
- Clear privacy positioning
- Strong CTA
- Responsive from mobile upward
- Reduced-motion support

## Sections
1. Hero
2. Security philosophy
3. Three product principles
4. Closing CTA

## Animation rules
- Prefer transform and opacity
- Use Motion for scroll-triggered reveals
- Keep floating elements subtle
- Respect prefers-reduced-motion
- Avoid animation that blocks interaction or reading

## Product-language rule
The homepage must distinguish between:
- the product's intended security architecture
- security features that are already implemented

Do not market E2EE as live until the cryptographic layer has actually been implemented and tested.
